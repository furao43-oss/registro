Privacidade e armazenamento

Os registros ficam primeiro no armazenamento local deste aparelho. Quando você conecta sua conta Google, o aplicativo sincroniza respostas, observações e registros escritos com a planilha que você escolher. As imagens anexadas permanecem somente no aparelho e nos backups exportados. O acesso à planilha é autorizado pelo Google e limitado ao arquivo escolhido pelo seletor do Drive.

Configuração inicial (uma vez)

  1. No Google Cloud Console, crie um projeto e habilite as APIs Google Sheets API e Google Picker API.
  2. Configure a tela de consentimento OAuth. Durante os testes, adicione sua própria conta Google como usuário de teste.
  3. Crie um ID do cliente OAuth do tipo Aplicativo da Web. Em “Origens JavaScript autorizadas”, informe a origem do GitHub Pages, por exemplo https://SEU-USUARIO.github.io (sem o caminho do repositório).
  4. Crie uma chave de API para o Google Picker. Restrinja-a à API Google Picker e ao endereço do seu site (incluindo o caminho do repositório, se aplicável).
  5. Copie o ID do cliente, a chave de API e o número do projeto para os campos acima e clique em “Salvar configuração”.
  6. Clique em “Conectar conta Google” e depois em “Escolher planilha”. Selecione a planilha existente Registro de Verdade - Dados Privados, com a aba Registros. Não crie uma planilha nova.
  7. Repita a conexão e a seleção da mesma planilha em cada aparelho. Depois disso, use “Sincronizar agora” sempre que quiser forçar uma sincronização.
Migração: o armazenamento local do aplicativo antigo não é copiado automaticamente para este novo endereço. Antes de abandonar a versão antiga, exporte um backup em “Histórico e backup”. Depois, importe o arquivo nesta versão e sincronize. Os dados que já estão na planilha serão baixados quando você conectar.

O código do aplicativo não contém chave privada nem senha. O ID OAuth e a chave de API identificam o projeto; o acesso aos dados depende da autorização concedida pela sua conta Google.
